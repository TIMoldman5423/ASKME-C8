Board papers

Board packs, Finance Board Reports, minutes and agendas (PDF). Choose as many as you like at once. For each one the app keeps the text of every page (so a question can be pointed at the page) and asks Claude for a short summary with key points and decisions. Loading a paper that is already held replaces it and keeps its link. The summaries are machine-written; the original paper stays the reference.

Load summaries file (summaries.json, written ahead of time). Papers already held are updated at once; for the rest the summary is kept by file name and used when you load the PDF, so no call to Claude is needed.
